# Security Policy

## Reporting a vulnerability

Ikke rapporter mulige sikkerhetssårbarheter som et offentlig GitHub Issue.

Bruk GitHubs private sikkerhetsrapportering dersom dette er aktivert for repositoryet. Hvis privat sikkerhetsrapportering ikke er tilgjengelig, kontakt repositoryets vedlikeholdere gjennom en privat kanal før tekniske detaljer publiseres.

Ikke legg ved arkivuttrekk, personopplysninger, autentiseringsinformasjon eller annet sensitivt materiale i en offentlig rapport.

## Public issues

Vanlige programfeil uten sikkerhetsmessige konsekvenser kan rapporteres gjennom repositoryets Bug report-skjema.

Dersom du er usikker på om en feil er sikkerhetsrelevant, behandle den som sikkerhetsrelevant og bruk privat rapportering.
