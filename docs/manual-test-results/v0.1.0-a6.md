# Manuelt testresultat v0.1.0-a6

**Dato:** 2026-08-27  
**Status:** Gjennomført med funn videreført til a7

## DIAS metadata / METS-import

- DIAS-dialogen åpnet og to-kolonne-oppsettet `METADATA | PAKKESTRUKTUR` ble kontrollert mot SIARD Workflow Manager.
- Eksisterende METS/info.xml ble lest inn og de forventede DIAS-metadatafeltene ble fylt.
- Metadatafeltsettet ble vurdert som i hovedsak på linje med SIARD-dialogen, med `Arkivtype = NOARK-5` som tilsiktet forskjell.

## Funn

- `Legg til fil` / `Fjern` manglet i pakkestrukturen.
- Visningen av Noark 5-innhold som eksplisitt «låst» ble vurdert som for restriktiv. DIAS-pakken må kunne suppleres med filer på valgte plasseringer, blant annet under `content/`, `administrative_metadata/repository_operations/` og `descriptive_metadata/`.

Disse funnene er planlagt løst i v0.1.0-a7.
